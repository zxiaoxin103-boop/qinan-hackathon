# 亲安 (Qin'an) — 让亲人安心

An AI-powered companion app for elderly people, built for AI Builders Hackathon 2026.

## Features
- 📸 Medicine box recognition (AI-powered photo reading)
- 🛡️ Scam call detection with explanations
- 🤸 Fall detection with alarm system
- 💊 Medication reminders
- 🌐 Multi-language support (Chinese/English)
- 👨‍👩‍👧 Family member dashboard

## Tech Stack
- HTML/CSS/JavaScript (Web version)
- DashScope (Alibaba Cloud) AI API
- Web Speech API for voice

## How to Run
Open index.html in a browser, or serve with:
python -m http.server 8767
